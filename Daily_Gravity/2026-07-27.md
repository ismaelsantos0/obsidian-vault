### 🚀 Construção do Bot N8N para Obsidian

Hoje nós construímos uma automação incrível e ultra robusta usando N8N, WhatsApp (ConectaZap/Evolution API) e GitHub API.

**O que o bot faz:**
- Ele monitora mensagens no meu WhatsApp.
- Ele possui um filtro (Nó IF) que **só deixa passar mensagens que começam com `/salva`**.
- Tudo o que eu envio com o comando `/salva` é enviado automaticamente e diretamente para uma nota diária (Daily Note) no meu Obsidian.
- O robô sabe quando deve **criar** a nota do dia do zero (se eu ainda não anotei nada) e quando deve apenas **atualizar** (empilhar o texto) se o arquivo do dia já existe, utilizando o `sha` da API do GitHub.
- Criamos também um "Código Caçador" hiper-inteligente para o caso do WhatsApp esconder a mensagem original quando eu uso o botão de "Responder".

Foi um projeto desafiador por conta de peculiaridades da API do ConectaZap e limites do GitHub, mas o sistema está 100% blindado agora! 🤖✨
