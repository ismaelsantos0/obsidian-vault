**DATA:** 2026-07-13
**ASSUNTO/PROJETO:** [[Agendamento]], [[API_WhatsApp]], [[ConectaZap]], [[Controle_de_Material]]
**ASSUNTO DE FATO:**
O dia foi focado na evolução, segurança e criação de múltiplos sistemas. Inicialmente, houve a migração do sistema de autenticação do projeto de agendamento para o uso seguro de cookies HttpOnly via SuperTokens e a adição de Rate Limiting, acompanhado de extensa documentação do backend. Em seguida, iniciou-se o desenvolvimento do zero de um Micro SaaS focado em gestão e integração com WhatsApp via Evolution API, inicialmente batizado de ZapFlow e posteriormente renomeado para ConectaZap. O novo SaaS ganhou arquitetura Multi-Tenant, gerenciamento de instâncias, documentação interativa para os clientes e proxy de Webhooks. Por fim, o sistema de controle de material foi integrado ao WhatsApp para disparos e cobranças diretas, além de ajustes no padrão de download de termos de cautela.

**O QUE FOI DECIDIDO E FEITO:**
- **Agendamento:**
  - Removido o uso inseguro de tokens JWT via `localStorage`.
  - Migrado e validado o fluxo de autenticação para utilizar SuperTokens com cookies `HttpOnly`.
  - Reduzido o tempo de expiração do login de 24 horas para 8 horas (duração de um turno).
  - Adicionado Rate Limiter (`slowapi`) para barrar ataques de força bruta no login e mitigar DDoS.
  - Gerada vasta documentação do funcionamento da API e arquitetura do backend.
- **Controle de Material / Patrimônio:**
  - Padronizada a nomenclatura de download de PDFs: `"NOME DO MATERIAL-NOME DO MILITAR- DATA.pdf"` e `"DIVERSOS_MATERIAIS-NOME DO MILITAR-DATA.pdf"`.
  - Criado o fluxo de testes de integração com WPP na tela de relatórios, adicionando botão para envio simulado para um militar.
- **Micro SaaS de WhatsApp (ConectaZap / ZapFlow):**
  - Construída arquitetura Multi-Tenant (Workspaces, Cargos e Limites).
  - Frontend desenvolvido (com base em prompts no Lovable) e Backend reformulado como API independente.
  - Ajustes extensos de deployment no Railway (adequação da versão do Node.js, remoção do NextAuth legado, configuração de Caddy/Nixpacks e liberação de CORS).
  - Implementado um "Gateway de Webhooks" onde a Evolution API notifica o SaaS e este repassa o payload para a URL configurada pelo cliente.
  - Desenvolvida página completa de "Documentação" no frontend, com exemplos em múltiplas linguagens e a funcionalidade inovadora de "Prompt Mágico" para facilitar o uso de IAs.
  - Ajustes de UX: inclusão de botão para copiar o ID da Instância e substituição da engrenagem cenográfica por um botão funcional de exclusão (lixeira).
  - Adicionado Fallback Inteligente no fluxo de leitura do QR Code para garantir a confirmação de status "Online" em caso de falha de conexão inicial.
  - **Decisão de Rebranding:** Alteração do nome "ZapFlow" para "ConectaZap". O design (inicialmente com estilo "glassmorphism" e "neon") foi alterado para um visual B2B mais sólido e corporativo (tema dark cinza fosco e verde clássico), substituindo também os ícones e o favicon pelo formato "PlugZap".
