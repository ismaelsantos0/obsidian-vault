**DATA:** 2026-07-14
**ASSUNTO/PROJETO:** [[ConectaZap]], [[Agente_IA]]
**ASSUNTO DE FATO:** 
O usuário e a IA desenvolveram a funcionalidade de Agentes de IA nativos para resposta automática no WhatsApp dentro do ConectaZap. Conversaram sobre a viabilidade técnica e financeira, definindo a criação de um sistema de "créditos" para limitar os gastos com a API de IA.
Houve resolução de problemas na configuração do Railway e do Frontend com o Next.js (SSR), especificamente envolvendo as variáveis de ambiente (`VITE_API_URL`), erro de CORS e caching de build.
Decidiram trocar o modelo de IA de OpenAI (GPT-4o Mini) para o Google Gemini devido à relação custo-benefício. Enfrentaram erros de cota e limites (429) no `gemini-2.0-flash` e versões não encontradas (404) no `gemini-1.5-flash`, resolvendo ao buscar dinamicamente os modelos disponíveis na conta do Google e escolhendo o ideal.
Criaram ferramentas de administração via endpoints ocultos para adicionar créditos aos workspaces e apagar usuários para "resetar" a base. O fluxo completo de mensagens pela Evolution API v2 (recebimento e disparo) foi ajustado e validado. Ao final, o usuário concluiu que a IA não mantinha o contexto da conversa e decidiram que seria necessário futuramente implementar um banco de dados para o contexto/memória da IA.

**O QUE FOI DECIDIDO E FEITO:**
- Desenvolvido e aprovado o módulo "Agentes IA" para o painel do ConectaZap.
- Adicionada tabela `Agent` e coluna `iaCredits` no banco de dados.
- Configurada comunicação entre o front e back no ambiente de produção usando proxy reverso no Nitro.
- Realizada a migração da API OpenAI para o SDK `@google/generative-ai` (Gemini).
- Definido o modelo `gemini-flash-lite-latest` como padrão devido aos limites da API gratuita do Google.
- Criada rota de administração `/api/admin/credits` (protegida por `ADMIN_SECRET`) para gerenciar o saldo de IA e limpar a base de usuários do sistema.
- Ajustada a compatibilidade dos payloads do webhook para a versão 2 da Evolution API.
- Resetado o banco de dados de usuários pelo usuário via console do navegador.
- Decidido: Adicionar futuramente um armazenamento de contexto para a IA, dado que as respostas estavam sem memória das interações passadas.
