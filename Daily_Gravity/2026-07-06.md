**DATA:** 2026-07-06
**ASSUNTO/PROJETO:** [[app-annalicia]], [[annalicia-front]], [[annalicia-back]]
**ASSUNTO DE FATO:** Resolução de travamentos no PWA iOS, conserto da vitrine que estava fora do ar devido a problemas de configuração de ambiente e implementação de grandes melhorias de UI/UX, SEO e URLs amigáveis.
**O QUE FOI DECIDIDO E FEITO:**
- **Correção no app-annalicia (PWA):** Realizada tentativa de usar `App.tsx` isolado para consertar tela branca no iOS, porém posteriormente o arquivo `main.tsx` foi revertido para usar o `AdminDashboard` original a fim de estabilizar o PWA.
- **Recuperação da Vitrine (annalicia-front):** A loja estava quebrada tentando ler produtos de `localhost:8000` em vez de produção. A URL de fallback foi ajustada para a de produção, o arquivo `.env` foi removido do rastreamento do Git para não sobrescrever variáveis da Railway, e um bug crítico (ReferenceError) no SSR ao acessar o `window` foi corrigido.
- **Melhorias Visuais e de UI na Vitrine:** Implementados Skeleton loading, overlay de "Esgotado", galeria de imagens mobile (swipe), botão "Voltar ao topo", WhatsApp flutuante, campo de busca de produtos e contagem de itens por categoria nos filtros.
- **Página de Produto Individual e Backend:** Criado o endpoint público `GET /produtos/:id` no backend (annalicia-back), desenvolvida a rota `/produto/:id` no frontend com botão de compartilhamento via Web Share API e seção de produtos relacionados ("Você também pode gostar"). Adicionados horário de funcionamento e endereço no banco de dados e footer da loja.
- **URLs Amigáveis (Slugs):** Substituição dos UUIDs na navegação por URLs amigáveis (ex: `/produto/vestido-azul`). Inserida correção no backend para lidar adequadamente com produtos de nomes duplicados, anexando um sufixo quando necessário.
- **SEO e Previews de Link no WhatsApp:** Implementadas meta tags SSR para os produtos. Após problemas de limite de tamanho e validação do WhatsApp, instalada a biblioteca `Pillow` no servidor para converter/comprimir dinamicamente a foto da miniatura para JPEG leve (~50KB) e adicionado a extensão explícita `.jpg` no endpoint da imagem para garantir que o preview renderize no aplicativo.
