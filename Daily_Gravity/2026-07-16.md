**ASSUNTO/PROJETO:** [[Integração_N8N_Loja]], [[Link_Preview_WhatsApp]], [[Prompt_Engineering_IA]], [[Checkout_WhatsApp]], [[Horario_Funcionamento_IA]], [[Arquitetura_Agentes]]
**ASSUNTO DE FATO:** Configuração de microserviços no FastAPI para integração segura com N8N, melhorias agressivas de prompt da IA para evitar alucinação de links, ajustes no Open Graph e backend para funcionamento do Link Preview no WhatsApp, implementação e posterior cancelamento do fluxo de checkout via chat, criação de sistema de horário de expediente e evolução da arquitetura de agentes no SaaS.
**O QUE FOI DECIDIDO E FEITO:** 
- **Decidido/Feito:** Criado um microserviço (`/produtos/search`) no backend FastAPI para o N8N consultar produtos, abandonando o nó nativo do Postgres que travava frequentemente.
- **Decidido/Feito:** Ajustes no Evolution API com delay de 3 segundos simulando digitação (`presence: "composing"`) para dar tempo ao WhatsApp de baixar a thumbnail.
- **Decidido/Feito:** Ajuste de infraestrutura para converter Base64 do banco de dados em imagens leves (Pillow/JPEG) na URL da loja, para contornar a restrição de tamanho de meta tags (`og:image`) do WhatsApp Mobile.
- **Decidido/Feito:** Injeção de "Travas de Segurança Globais" no backend e ajustes nas Regras de Ouro (Prompt) proibindo a IA de inventar URLs quando a busca não retorna produtos e forçando o plural para singular nas buscas.
- **Decidido/Feito:** Atualização do Prompt para enviar cada produto com espaçamento de dois "Enters", permitindo a renderização do link preview de múltiplos itens.
- **Recusa/Reversão:** A IA chegou a criar um fluxo completo de checkout manual via PIX no WhatsApp (`/pedidos/whatsapp` no backend + novo fluxo no N8N), porém o usuário decidiu reverter a decisão para manter a jornada de compra simples (apenas clicando no link).
- **Decidido/Feito:** Aprovação e início da implementação de bloqueio da IA fora do horário de funcionamento, respondendo mensagens fixas para economizar requisições da IA.
- **Decidido/Feito:** Aprovação da refatoração de "Modelos de Agentes", permitindo criar templates desvinculados que podem ser conectados a múltiplas instâncias de WhatsApp simultaneamente.
