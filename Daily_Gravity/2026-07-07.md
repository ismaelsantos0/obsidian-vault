# Walkthrough: Portfólio Estilo Spotify 🎧

Pivô realizado com sucesso! O antigo tema de Pixel Art foi completamente deletado e o seu portfólio agora possui uma interface **Glassmorphism Premium** estilo Apple/Spotify.

## 🎛️ O que foi construído?

- **Cover Flow 3D:** Construímos um carrossel em 3D usando `framer-motion`. Os projetos deslizam de um lado para o outro. O projeto que está no centro fica em foco (maior e com brilho total), enquanto os das laterais ficam menores, levemente escuros e rotacionados em 3D.
- **Background Dinâmico:** Cada projeto tem uma cor base configurada. Conforme você gira o carrossel, o fundo da tela faz uma transição super suave (fade) para a cor daquele projeto, exatamente como o Spotify faz com as capas dos álbuns!
- **Barra de Controle (Player):** Na parte inferior da tela, temos uma barra com efeito de "Vidro Fosco" (Blur/Glassmorphism). Ela possui:
  - Botões de Próximo e Anterior (que giram os projetos).
  - Um botão de **Play** central, que quando clicado abre o link do projeto focado.
  - O seu mini-perfil (Ismael Santos - Developer & Micro SaaS).
  - Um link direto para o seu GitHub.
