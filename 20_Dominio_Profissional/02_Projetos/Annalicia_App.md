# Annalicia App - E-commerce

Sistema completo de e-commerce para a loja da esposa. Possui site publico para clientes e painel administrativo para gestao de pecas e vendas.

## Visao Geral

| Modulo | Para quem | Descricao |
|--------|-----------|-----------|
| Site Publico | Clientes da loja | Vitrine de pecas, carrinho e pedidos |
| Painel Admin | Esposa (gestora) | Cadastro de pecas, gestao de estoque, visualizacao de vendas |

## Stack Tecnologico

| Camada | Tecnologia |
|:---|:---|
| Frontend Web | React / TypeScript / Vite / Shadcn UI |
| Backend | FastAPI (Python) |
| Banco de Dados | PostgreSQL |
| Mobile (futuro) | Capacitor |
| Deploy | Railway (Back) + Vercel (Front) |
