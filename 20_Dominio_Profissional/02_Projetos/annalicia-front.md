# 💻 Annalicia Frontend (annalicia-front)

Repositório frontend (interface de usuário) da aplicação Annalicia. Criado a partir do `retail-elegance-kit`.

## 🛠️ Tecnologias
- **Framework:** React + TypeScript + Vite
- **UI Components:** Shadcn UI
- **Estilização:** Tailwind CSS
- **Deploy:** Vercel / Railway
